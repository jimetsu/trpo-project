1. Observer — наблюдатель

Позволяет нескольким элементам страницы автоматически обновляться при изменении общего состояния. При выборе книги обновляются карточка, счётчик просмотров и журнал событий.

2. Strategy — стратегия

Позволяет менять алгоритм сортировки списка книг во время работы программы без изменения основного кода.

3. Command — команда

Каждое действие над библиотекой оформляется отдельной командой. Команды можно выполнять и отменять.

Выполненные действия появятся здесь.

4. Singleton — одиночка

Гарантирует существование единственного экземпляра общего объекта журнала действий. Разные части программы обращаются к одному и тому же объекту.

Нажмите кнопку для проверки.
